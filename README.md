# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина одежды и обуви.

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина одежды и обуви без CSS-фреймворков: 36 связанных страниц, единая навигация, каталог на 30 товаров с фильтром, отдельная страница каждого товара, форма заказа, модальное окно быстрого заказа, CSS-переменные, Flexbox и Grid, БЭМ и позиционирование. Опубликованная версия: https://klpbvcvc.github.io/KR1-fr-bk-679832/

## Структура проекта

- `index.html` - главная страница (три экрана на высоту окна: hero, «Популярное», «Преимущества»);
- `catalog.html` - каталог товаров (30 товаров, фильтр по категории и цене без JS, плашка со ссылкой на «Как выбрать размер»);
- `product.html` - карточка товара «Джинсы» с таблицей характеристик;
- `product-jacket.html`, `product-hoodie.html` и ещё 27 страниц `product-<название>.html` - у каждого из 30 товаров своя страница с описанием, таблицей характеристик, таблицей размеров и блоком «Похожие товары»;
- `size.html` - «Как выбрать размер»: как снять мерки и таблицы размеров по группам товаров;
- `404.html` - страница ошибки для GitHub Pages (стили и ссылки абсолютные);
- `order.html` - страница оформления заказа: форма с выбором товара, адресом, комментарием и переключателями;
- `contacts.html` - контактная информация, обратная связь и вопросы про доставку и оплату;
- `css/style.css` - единый файл стилей проекта;
- `js/main.js` - скрипт модального окна и обработки формы;
- `js/ui.js` - переключатель темы и показ кнопки «Наверх» (подключён на всех страницах);
- `images/` - изображения товаров (Unsplash);
- `.gitignore` - список файлов, исключённых из Git;
- `README.md` - описание проекта.

## Используемые технологии

- HTML5 (семантическая разметка);
- CSS3 (Custom Properties, Flexbox, Grid, Sticky/Fixed позиционирование, анимации);
- JavaScript (минимально: модальное окно `<dialog>`, обработка формы, переключатель темы и кнопка «Наверх»);
- Шрифты Google Fonts: Montserrat (заголовки) и Inter (основной текст);
- Git и GitHub (ветвление, Pull Requests, GitHub Pages).

## Текущий статус

Реализована контрольная работа №1 в полном объеме с расширенными самостоятельными доработками:
- Полноширинный главный экран (Hero) с атмосферным фотофоном во всю ширину окна и тёмным полупрозрачным наложением (`--color-overlay`), чтобы белый текст читался на фото;
- Строгая архитектурная геометрия без скруглений (`--radius-sm`, `--radius-md`, `--radius-lg` равны `0px`) в стиле минимализма;
- Промо-плашка (`.top-bar`) над шапкой на главной странице: стоит в обычном потоке, поэтому уходит при прокрутке сама, закрывается крестиком через скрытый checkbox и `:has()` без JavaScript;
- Липкая шапка (`position: sticky`) с защитой якорных переходов (`scroll-padding-top: var(--header-height)`);
- Плавающая квадратная кнопка «Наверх» (`position: fixed`) в правом нижнем углу, якорная ссылка на `#top`; плавно появляется (`opacity` + `transition`), когда первый экран (hero) пролистан целиком, класс `to-top--visible` ставит `js/ui.js`;
- Фирменная палитра «Благородный бордо и слоновая кость» с проверенным контрастом по WCAG. Все цвета, тени, шрифты и отступы вынесены в токены `:root`: `--color-primary` (бордо, в том числе для «Скидки»), `--color-accent` (латунь, для «Новинки»), `--color-danger` только для ошибок форм;
- Тёмная тема: по умолчанию берётся тема системы (`prefers-color-scheme: dark`), кнопка в шапке переключает её вручную (`data-theme` на `<html>`, выбор хранится в `localStorage`). Переопределяются только токены `:root` (цвета, тени, `--color-on-primary`), правила компонентов не меняются; `color-scheme` настраивает поля формы и диалог;
- Плашка «Не уверены в размере?» в начале каталога со ссылкой на страницу «Как выбрать размер»;
- Якорь `:target`: заголовок целевой секции окрашивается в основной цвет, без рамок и `!important`;
- Три экрана главной (hero, «Популярное», «Преимущества») каждый ровно на высоту окна под липкой шапкой: у «Популярного» и «Преимуществ» блок `.screen` с `min-height: calc(100svh - var(--header-height))`, у hero собственное правило, где дополнительно вычитается высота промо-плашки (`--top-offset`);
- Интерактивный блок преимуществ на чистом CSS (радиокнопки внутри меток вкладок и селектор `:has()`, без JavaScript) с 6 пунктами: вкладки делят высоту блока поровну (`flex: 1 1 0`);
- Фильтр каталога без JavaScript: radio-группы «категория» и «цена», карточки скрываются селектором `:has()` по атрибутам `data-category` и `data-price`; панель фильтров липкая (`position: sticky`);
- Своя страница у каждого из 30 товаров, блок «Похожие товары» (три карточки той же категории с близкой ценой), у «Скидки» и «Новинки» бейдж на фото, нативные аккордеоны `<details>` с таблицей размеров и FAQ;
- Таблица сравнения (куртка, бомбер, пальто) на страницах этих трёх товаров, колонка текущего товара выделена;
- Центрированная плашка «О магазине»;
- Двухколоночный подвал (Sticky Footer) с прижатием к низу окна: слева текст и источник изображений, справа ссылка «Контакты»;
- Условные хлебные крошки на странице заказа через `:target` (товар, с которого пришёл пользователь).

## Самостоятельные доработки

Сверх базовой инструкции по практическим занятиям сделано следующее:

- Собственные страницы и разделы: отдельные страницы для 30 товаров, страница «Как выбрать размер», страница ошибки `404.html`, блок «Похожие товары», FAQ про доставку и оплату, таблица сравнения курток.
- Собственное визуальное оформление: палитра «бордо и слоновая кость», шрифты Montserrat и Inter, нулевые скругления, тёмная тема на тех же токенах `:root`, три экрана главной на высоту окна.
- Карточки товаров: бейджи «Скидка» и «Новинка» (`relative` и `absolute`), модификатор `product-card--discount`, фильтр по категории и цене на чистом CSS (`:has()`), подсветка карточки при наведении.
- Формы и сценарий заказа: быстрый заказ в `<dialog>` с выбранным товаром, полная форма заказа с выбором товара, переключатели `role="switch"`, дата звонка, подсветка невалидных полей через `aria-invalid`, сообщение об успешной отправке.
- Навигация и структура: хлебные крошки (условная крошка через `:target`), липкая шапка и липкий фильтр, внутренние ссылки между товарами, размерами и каталогом.
- Доступность: видимый `:focus-visible`, подписи у всех полей, `aria-label` у кнопок без текста, проверенный контраст в обеих темах, нативные `<details>` для аккордеонов.
- Организация кода: БЭМ без стилизации по id, токены вместо повторяющихся значений, единый файл стилей с разделами, один общий шаблон подвала и шапки на всех страницах (без шаблонизатора HTML повторяется вручную, это будет заменено на компоненты в следующих контрольных).

## Позиционирование элементов (CSS Positioning)

В проекте комплексно используются различные типы позиционирования:
- `position: relative` и `position: absolute`: для бейджей скидок и новинок (`.product-card__badge`) относительно карточки товара (`.product-card`);
- `position: sticky`: для шапки сайта (`.site-header`), которая при прокрутке фиксируется у верхнего края окна (`top: 0`). Для предотвращения перекрытия якорных заголовков липкой шапкой на `html` задан `scroll-padding-top: var(--header-height)`;
- `position: fixed`: для плавающей кнопки «Наверх» (`.to-top`), зафиксированной в правом нижнем углу экрана (`bottom: 24px; right: 24px;`);
- Уровни наложения (`z-index`):
  - `z-index: 1` - бейджи карточек товаров;
  - `z-index: 9` - кнопка «Наверх»;
  - `z-index: 10` - липкая шапка;
  - Верхний слой (Top Layer браузера) - диалоговое окно `<dialog>`, открываемое через `showModal()`.

## CSS-архитектура

В проекте используются:
- CSS-переменные в `:root` (цвета, шкала отступов, радиусы скруглений, ширина контейнера);
- Палитра: основной фон слоновая кость (`#f9f8f6`), текст графит (`#2a2a2a`), акцентный бордо (`#8b1e2d`), поверхности (`#f1ede6`);
- Единый контейнер `.container` (`max-width: 1100px; margin: 0 auto;`);
- Техника Sticky Footer (`min-height: 100vh` + `display: flex; flex-direction: column` на `body`, `flex: 1` на `main`);
- Состояния интерактивности: `:hover`, `:focus-visible`, `:disabled`;
- Микроанимации при наведении на карточки товаров (`transform: translateY(-4px)` + тень);
- Подсветка ошибок формы через `[aria-invalid="true"]`.

## Использование Flexbox и Grid

В проекте используются:
- Flexbox: компактная шапка сайта (`justify-content: space-between`), список навигации, трехколоночный подвал (`.site-footer__inner`), вертикальная раскладка карточек товаров и центрирование главного экрана Hero;
- CSS Grid: сетка товаров (`.products-grid`, 3 колонки), каталог товаров с фильтрами (`.catalog-layout`).

## БЭМ-структура проекта

Классы названы строго по методологии БЭМ: блок `block`, элемент `block__element`, модификатор `block--modifier`.

Основные блоки:
- `container` - универсальный блок ограничения ширины и центрирования;
- `top-bar` (`__inner`, `__text`, `__code`, `__close`, `__toggle`) - промо-полоса над шапкой с информацией о доставке;
- `site-header` (`__inner`, `__logo`) - шапка сайта;
- `site-nav` (`__list`, `__item`, `__link`, модификатор `--active`) - основная навигация;
- `breadcrumbs` (`__link`, `__current`, `__item`, модификатор `--conditional`) - хлебные крошки;
- `hero` (`__inner`, `__title`, `__text`) - главный блок с фотофоном;
- `screen` (`__inner`) - секция главной на высоту окна;
- `theme-toggle` (`__icon`) - кнопка переключения темы в шапке;
- `size-guide` (`__summary`, `__content`) - таблица размеров в `<details>`;
- `faq` (`__item`, `__question`, `__answer`) - вопросы и ответы;
- `product-table--compare`, `product-table__link` - таблица сравнения;
- `section` (`__title`) - секция страницы;
- `products-grid` - сетка карточек;
- `product-card` (`__image-link`, `__image`, `__title`, `__description`, `__price`, `__button`, `__badge`, модификаторы `--discount`, `__badge--sale`, `__badge--new`) - карточка товара;
- `product` (`__media`, `__badge`, `__image`, `__info`, `__title`, `__price`, `__description`) - детальная карточка товара;
- `product-table` (`__caption`, `__head`, `__body`, `__row`, `__cell`) - таблица характеристик товара;
- `catalog-layout`, `catalog-filters`, `catalog-products` - раскладка каталога;
- `filters-form` (`__group`, `__legend`, `__label`, `__radio`) - форма фильтров;
- `order-dialog` (`__close`, `__title`, `__note`) - модальное окно быстрого заказа;
- `order-form` (`__field`, `__field--callback`, `__label`, `__input`, `__input--date`, `__textarea`, `__select`, `__hint`, `__actions`, `__switch`, `__switch-input`, `__switch-text`, `__switch-text--on`, `__switch-text--off`, модификатор `--page`) - форма заказа;
- `advantages` (`__radio`, `__grid`, `__tabs`, `__tab`, `__num`, `__tab-title`, `__panels`, `__panel`, `__image`, `__desc`, `__heading`, `__text`) - интерактивный блок преимуществ;
- `aside-info` (`__title`, `__text`, `__body`, модификатор `--inline`) - информационная плашка;
- `to-top` (модификатор `--visible`) - плавающая кнопка возврата наверх;
- `button` (модификаторы `--primary`, `--secondary`) - кнопки;
- `site-footer` (`__inner`, `__col`, `__copy`, `__meta`, `__nav`, `__list`, `__item`, `__link`, `__credits`) - подвал сайта.
