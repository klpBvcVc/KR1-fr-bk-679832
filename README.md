## БЭМ-структура проекта

Классы названы по методологии БЭМ: блок `block`, элемент `block__element`, модификатор `block--modifier`. Модификатор всегда пишется вместе с базовым классом (`button button--primary`). Стили задаются по классам, без стилизации по `id` и без инлайн-стилей.

Основные блоки:

- `site-header` (элементы `__inner`, `__logo`) - шапка сайта;
- `site-nav` (`__list`, `__item`, `__link`, модификатор `--active`) - основная навигация;
- `breadcrumbs` (`__link`, `__current`) - хлебные крошки;
- `hero` - главный экран;
- `section` (`__title`) - секция страницы;
- `products-grid` - сетка карточек;
- `product-card` (`__title`, `__description`, `__price`, `__button`, модификаторы `--featured`, `--discount`) - карточка товара;
- `catalog-layout`, `catalog-filters`, `catalog-products` - раскладка каталога;
- `filters-form` (`__group`, `__legend`, `__label`, `__input`) - форма фильтров;
- `order-dialog` (`__title`) и `order-form` (`__field`, `__label`, `__input`, `__select`, `__textarea`, `__hint`, `__actions`, `__switch`, `__switch-input`, `__switch-text`, модификатор `--page`) - модальное окно быстрого заказа и форма заказа;
- `button` (модификаторы `--primary`, `--secondary`) - кнопки;
- `site-footer` - подвал сайта.
