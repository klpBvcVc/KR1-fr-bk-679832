Как выбрать размер

Мерки снимают по телу, а не по одежде. Если ваши мерки между двумя размерами, берите больший для свободного кроя и меньший для облегающего.

  1. Обхват груди: измерьте по самым выступающим точкам, лента проходит горизонтально под мышками.
  2. Обхват талии: измерьте по самому узкому месту, не втягивая живот.
  3. Обхват бёдер: измерьте по самым выступающим точкам ягодиц.
  4. Длина стопы: встаньте на лист бумаги, отметьте пятку и самый длинный палец, измерьте расстояние.
  5. Обхват головы: лента проходит над бровями и ушами по самой широкой части.
  6. Обхват ладони: измерьте по основанию пальцев, без большого пальца.
